# Confluence Space Template

Create a `Ctrl+Plant — Leafy AI` Confluence space with this page tree:

1. Project Home — objective, status, milestones and key links.
2. Requirements — stakeholders, use cases, functional/non-functional requirements and acceptance criteria.
3. Architecture — context, data flow, API contracts and ADR index.
4. Security & Safety — threat model, policy catalogue, risk register and incident process.
5. Sprints — Planning, Review and Retrospective child page for each Sprint.
6. Testing & UAT — test plan, AI evaluation, security evidence and signed UAT outcomes.
7. Operations — deployment, monitoring, maintenance, backup and recovery.
8. Decision Log — ordered ADR and project-decision register.

## ADR template

- Title and ADR number
- Status: Proposed / Accepted / Superseded
- Date, owner and Jira Change Task
- Context and constraints
- Options considered
- Decision and rationale
- Security, safety, data and licensing consequences
- Validation and rollback plan
- Review date

## Sprint Review template

- Sprint Goal and Scrum Master
- Completed Jira issues
- GitHub PRs and release/build reference
- Demonstration and test evidence
- Security and domain review results
- Stakeholder feedback
- Incomplete work and revised forecast
- Retrospective actions
- Compendium evidence checklist

## Teams decision capture

For any decision made in Teams, record the date, participants, issue, decision, rationale, owner and affected Jira issues in the Decision Log within one working day. Link back to the meeting only as supporting context.
